==================================================================
FRONTEND VALIDATION (MANDATORY)
==================================================================

All frontend validation MUST mirror the backend validation rules.

The backend API documentation is the SINGLE SOURCE OF TRUTH for:

- Required fields
- Data types
- Allowed characters
- String length constraints
- Phone number formats

--------------------------------------------------
GENERAL RULES
--------------------------------------------------

1. Every required field must include the `required` attribute.

2. Validation MUST happen BEFORE sending data to the backend.

3. Validation must be implemented in a dedicated validation function.

4. Validation errors must:
   - be user friendly
   - clearly explain the problem
   - prevent submission

--------------------------------------------------
PHONE NUMBER VALIDATION
--------------------------------------------------

whatsapp_number
- must start with "+"
- must contain only numbers after "+"
- must follow phone number rules

contact_number
- maximum two numbers allowed
- if two numbers are used they must be separated using "/"

Example valid input:

+251900000000

or

+251900000000/+251911111111

--------------------------------------------------
VALIDATION STRUCTURE
--------------------------------------------------

Create validation functions:

validateGallery()
validateSocialMedia()

Each function must:

- accept the form data object
- return an error message string if invalid
- return null if valid
