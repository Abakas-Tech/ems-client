STEP 1: UPDATE PASSPORT COMPONENT FOR CREATE + EDIT
==================================================================
1. Change the prop from `isEdit` to `mode` with value "create" or "edit".

   Example: function Passport({ mode }: { mode: "create" | "edit" })

2. Add a loading state for edit mode:
   const [isLoading, setIsLoading] = useState(mode === "edit");

3. In useEffect:
   - If mode === "edit", fetch the existing passport data (you will need getPassport API)
   - While fetching → keep isLoading = true
   - After fetch succeeds → set formData with the received values + setIsLoading(false)
   - If no data found → show message via addMessage("No passport found – creating new one") and treat as create mode

4. Show a simple loading message or spinner when isLoading is true:
   if (isLoading) return <div>Loading passport information...</div>;

5. Update handleSubmit:
   - If mode === "create" → call createPassport(id, FormData)
   - If mode === "edit" → call updatePassport(passportId, FormData)
     (save passportId from the fetch result)

6. Make UI dynamic:
   - Heading: mode === "create" ? "Add Worker Passport" : "Edit Worker Passport"
   - Button text: mode === "create" ? "Add Passport" : "Update Passport"

7. For the file input (passport scan):
   - In create mode: required (keep as is)
   - In edit mode: optional – show "Current file: [name/link]" if exists
   - Only send new file in FormData if user selects one

8. Keep all existing validation, hooks (useLoader, useResponse), and form structure
