1. Create or Update Social Media

Creates or updates social media information.

The system stores social media information in a single database record.
If no record exists, the request will create one.
If a record already exists, the request will update it.

Contact numbers allow a maximum of two numbers.
If two numbers are provided they must be separated using a slash "/".

Endpoint
POST /api/social-media

Content Type
application/json

Request Example

{
  "facebook_username": "company.page",
  "instagram_username": "company.official",
  "telegram_username": "company_support",
  "tiktok_username": "company.tiktok",
  "linkedin_username": "company-linkedin",
  "youtube_channel": "companychannel",
  "twitter_username": "company_x",
  "whatsapp_number": "+251922222222",
  "contact_number": "+251900000000/+251911111111"
}

Successful Response (Created)

Status: 201 Created

{

  "message": "Social media created successfully",
  "data": {
    "id": 1,
    "facebook_username": "company.page",
    "instagram_username": "company.official",
    "telegram_username": "company_support",
    "tiktok_username": "company.tiktok",
    "linkedin_username": "company-linkedin",
    "youtube_channel": "companychannel",
    "twitter_username": "company_x",
    "whatsapp_number": "+251922222222",
    "contact_number": "+251900000000/+251911111111",
    "updated_at": "2026-03-06T12:00:00Z"
  }
}

Successful Response (Updated)

2. Get Social Media Information

Returns the stored social media information.

Only one record exists in the system.

Endpoint
GET /api/social-media

Example Request
GET /api/social-media

Successful Response

Status: 200 OK

{
  "success": true,
  "message": "Social media retrieved successfully",
  "data": {
    "id": 1,
    "facebook_username": "company.page",
    "instagram_username": "company.official",
    "telegram_username": "company_support",
    "tiktok_username": "company.tiktok",
    "linkedin_username": "company-linkedin",
    "youtube_channel": "companychannel",
    "twitter_username": "company_x",
    "whatsapp_number": "+251922222222",
    "contact_number": "+251900000000/+251911111111"
  }
}

Empty Response

If no social media record exists.

{
  "success": true,
  "message": "Social media retrieved successfully",
  "data": null
}



3. Delete Social Media Information

Deletes the stored social media record.

Endpoint
DELETE /api/social-media

Example Request
DELETE /api/social-media

Successful Response

{
  "success": true,
  "message": "Social media deleted successfully"
}

Phone Number Rules

must start with "+" followed by country code
only numbers allowed after "+"
minimum length 10
maximum length 15

Example valid phone numbers

+251911111111
+251922222222


General Rule

At least one field must be provided when creating or updating social media.
